## Key decisions

- Independent source ownership is justified by an external developer task,
  independent installation, and independent release cadence.
- CLI plus Skill is the default product. A persistent MCP developer control
  plane is excluded until a real host cannot use the CLI and catalog cost is
  measured.
- Capability, Procedure, Direct Runtime, and Agent Host remain separately owned.
- Initial runtime target is macOS arm64 with current Codex and Claude host
  integrations; other hosts require physical runtime validation.
- Commit policy is no commit, push, publication, live installation, signing, or
  deployment without explicit owner authorization.
